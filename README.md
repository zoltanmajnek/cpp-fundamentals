# C++ Concepts and Data Structures Portfolio

This repository contains a collection of C++ projects and exercises that demonstrate fundamental and advanced concepts of the language. Each subfolder represents a standalone project or algorithmic challenge.

## Topics

Across the various projects in this repository, the following C++ concepts and techniques are implemented:

* **Custom Data Structures:** Implementation of data structures from scratch, including a Circular Buffer (FIFO) queue.
* **Memory Management:** Direct memory manipulation and safe handling of pointers.
* **Object-Oriented Programming (OOP):** Encapsulation, robust class design, and object lifecycles.
* **File I/O & Algorithms:** Reading from and writing to files, alongside custom sorting algorithms and data processing.
* **C++ Templates:** Generic programming to create flexible and reusable code components.
* **Operator Overloading:** Custom behavior for standard operators (e.g., `++`, arithmetic, and stream operators) to allow intuitive interaction with custom classes.

## Testing

Quality assurance is an integral part of this repository. The projects are accompanied by their own suites of unit tests (located in the `unittest.cpp` files). These files contain numerous test cases designed to verify the logic, handle edge cases, and ensure the overall correctness of the implemented data structures and algorithms.

## Repository Structure

Each project is contained within its own directory with its respective source files (`.cpp`, `.h`) and testing modules.
